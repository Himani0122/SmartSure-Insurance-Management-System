Detailed flow of the Saga orchestration pattern implemented using RabbitMQ for distributed transactions between the Policy Service and Payment Service during policy creation.

LLD: JWT Security Flow

Sequence illustrating how authentication and authorization are handled at the API Gateway using JWTs before requests reach downstream services.
